# smartfit-membership-program
A Python program that recommends fitness programs and membership plans based on user input

## What it does
- Recommend a Teen, Regular, or Senior program by age
- Checks medical conditions with logical operators
- Calculates Basic and Premium Membership Prices
- Applies a youth discount and gives upgrade or consultaltionadvice

 ## Skills practiced
 if/elif/else statements, logical operators, nested conditionals

 ## How to run
 Run 'smartfit.py' in python 3 and answer the prompts
